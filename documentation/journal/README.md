# Work journal

This folder traces exchanges and decisions worth keeping as project memory while building the
component.

| Folder | Role |
|--------|------|
| `inbox/` | Same-day entries and raw active material. |
| `archive/` | Entries already digested into an ADR, an issue or a document. |

Inbox file convention: `YYYY-MM-DD.md` (one or more entries per day), in English (WA001).

## Version control

Day files under `inbox/` and `archive/` are meant to stay local: only this `README.md` and the
`.gitkeep` files are tracked, so the layout stays clear for contributors. Do not rely on day files
being present in a fresh clone.
